## Earlier work this release builds on

- **Shiqi Xiang** developed the original code base as part of a Master's thesis (TFM) at
  Universidad Politécnica de Madrid: the profile-driven event generator, the daily
  feature extractor, the four reference scenarios, the distributional (Kolmogorov–Smirnov)
  validation, the five-seed detector benchmark and its figures, the differential-privacy
  noise and edge-profiling experiments, and the web application. The initial commit of
  this repository is derived from that work.

The sequential detectors (BOCPD and CUSUM), the trivial reference baselines, the 25-seed
protocol with paired significance tests, the privacy-budget sweep, and the threshold
ablation were added during the revision of the accompanying paper.
